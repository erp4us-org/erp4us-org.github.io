# Provisional erp4us identity

The connected four adapts the original application README mark. `symbol.svg` and `favicon.svg` are standalone vectors. `horizontal-light.svg` and `horizontal-dark.svg` include the wordmark; the four uses a darker green on light surfaces for contrast. Use `avatar.png` (512 square) for GitHub and `social.png` (1200 × 630) for social cards. These assets use system/open fonts; no web fonts are downloaded. Future proposals: https://github.com/erp4us-org/erp4us/issues/35.
