# erp4us identity

The connected four uses muted teal against slate. `symbol.svg`, `favicon.svg` and `app-icon.svg` are standalone vectors. Use the horizontal wordmark variant appropriate for the background, `avatar.png` (512 × 512) for GitHub and `social.png` (1200 × 630) for Open Graph. The equivalent SVG sources are `symbol.svg` and `social.svg`. Live profile avatar publication is separate from site deployment.

This directory vendors the application repository's `ui/public/brand/`. For a coordinated update, review an exact application commit, copy its files over the corresponding names here without reformatting, and record its SHA in the website changes. Run the website checks. Do not fetch mutable `main` or web fonts at runtime.
